# SAA-C03 Domain Map

| Domain | Exam weight | Guiding question |
| --- | ---: | --- |
| D1 Secure | 30% | Who can access what, through which trust boundary? |
| D2 Resilient | 26% | What fails and how can service recover? |
| D3 High-Performing | 24% | Which data/compute/network choices meet workload needs? |
| D4 Cost-Optimized | 20% | Which option meets requirements at acceptable total cost? |

Coverage is distributed as one documented exercise from every domain in every week. **These weights guide exam review, not the proportion of lab hours.**
