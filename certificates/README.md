# Public certificate documents

[English overview](../CREDENTIALS.md) · [Deutsche Übersicht](../CREDENTIALS.de.md)

This folder contains **twelve uploaded PDF files**: two redacted IBB training certificates, one Google Zukunftswerkstatt certificate, and nine AWS Training & Certification **course/module completion** certificates (seven SAP-C02 prep activities, one Amazon Kiro course and one AWS Cloud Practitioner Essentials course). The source PDFs were provided by the portfolio owner.

**Classification:** none of the AWS course/module completion documents proves that the **AWS Certified Solutions Architect – Professional (SAP-C02)** or **Cloud Practitioner (CLF-C02)** exam was passed. Do not label them as an AWS vendor certification.

The IBB PDF copies were generated from redacted source documents, with the original date of birth removed before public publication. The Google certificate has an issuer-provided verification link in the overview.

The Python/Data Science online training mentioned in a 2020 CV has **no original certificate scan here** and is deliberately not represented by a fabricated PDF.

For file-integrity checks, see [the SHA-256 manifest](../portfolio/certificates-manifest.json).
