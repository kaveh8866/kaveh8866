# سؤال ۰۰۱ — برگه تمرین معماری در Draw.io

[English](drawio.en.md) · [معرفی کیت](../README.fa.md)

**دیاگرام نهایی را خودت می‌کشی.** عمداً فایل آماده کامل نمی‌دهیم. تصویر سؤال اول **متن و گزینه‌های سؤال است، نه نمودار معماری**. هر زمان نمودار مرجع اختصاصی فرستادی، با مشخص‌کردن منبع و مجوز انتشار در این بخش ثبتش می‌کنیم.

## رسم دستی در https://app.diagrams.net

1. گزینه **Device** را برای ذخیره محلی بزن و از **Create New Diagram → Blank Diagram** شروع کن. نام: `Q001-bicycle-location-api.drawio`.
2. اگر وجود داشت از **More Shapes → AWS Architecture** آیکون‌ها را فعال کن؛ مستطیل ساده هم کافی است. زمان زیادی صرف پیدا کردن آیکون نکن.
3. از چپ به راست یک **Client تولیدکننده GPS ساختگی** در بیرون AWS، مرز **AWS Cloud**، سرویس **Amazon API Gateway HTTP API** و **AWS Lambda** را قرار بده.
4. زیر Lambda یک **CloudWatch Log Group** بکش و با پیکان نقطه‌چین **execution logs** وصل کن؛ CloudWatch را پایگاه داده تاریخچه GPS نشان نده.
5. روی مرز **Client → API** عبارت `AWS_IAM / SigV4` را بنویس؛ کنار Lambda نقش `IAM execution role` را بگذار.
6. پیکان ورودی `POST /locations`، پیکان اتصال `Lambda proxy integration v2.0` و پیکان پاسخ `HTTP 202 + accepted=true, stored=false` را علامت بزن.
7. یک کادر جدا و نقطه‌چین با عنوان `DynamoDB / location history — NOT IN THIS LAB` رسم کن؛ وانمود نکن واقعاً اجرا شده است.
8. در حاشیه بنویس: `Kinesis / Flink — پردازش جریان در معماری کامل؛ در این لَب اجرا نشده`.
9. در راهنمای شکل: **خط ممتد = جزء برنامه‌ریزی‌شده یا تست‌شده پس از اجرا**؛ **خط نقطه‌چین = قابلیت احتمالی/خارج از آزمایش**. پیش از اجرای AWS کنار سرویس‌ها بنویس **planned**.
10. خروجی PNG یا SVG بگیر و فایل قابل‌ویرایش draw.io را هم نگه دار؛ پس از بررسی اطلاعات حساس، آن‌ها را به پوشه‌های `diagrams/source/` و `diagrams/exported/` کیت اضافه کن.

## خودآزمایی

- [ ] می‌دانم چرا API پیام را می‌پذیرد ولی آن را ذخیره نمی‌کند.
- [ ] مجوز IAM فراخواننده را از نقش اجرایی Lambda تمیز می‌دهم.
- [ ] مسیر شکست برای درخواست بدون امضا یا داده نامعتبر را نشان می‌دهم.
- [ ] می‌توانم توضیح بدهم افزودن پایگاه داده نمودار را چگونه تغییر می‌دهد.
- [ ] می‌توانم دیاگرام را بدون نگاه به برگه تمرین دوباره رسم کنم.

**تمرین پورتفولیو:** زیر دیاگرام با عبارت خودت بنویس این میکرو-لب چه چیزی را نشان می‌دهد و چه چیزی را اثبات نمی‌کند.
