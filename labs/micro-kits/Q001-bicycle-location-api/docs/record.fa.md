# سؤال ۰۰۱ — فرم ثبت نتایج آزمایش

[English](record.en.md)

**وضعیت فعلی: هنوز روی AWS اجرا نشده.** خانه‌های خالی به معنی موفقیت نیستند.

- اجراکننده/تاریخ: _در انتظار_
- Region/نوع پلن (بدون شماره حساب): _در انتظار_
- مسیر اجرا: _فقط مشاهده / کنسول / Terraform / محلی_ (هنگام اجرا انتخاب کن)
- هزینه احتمالی بررسی شد؟ _در انتظار_
- دیاگرام شخصی Draw.io ترسیم شد؟ _در انتظار_

## مشاهدات

| تست | نتیجه مورد انتظار | نتیجه واقعی (فقط پس از اجرا) |
| --- | --- | --- |
| تست‌های محلی | موفق | هنوز در این گزارش اجرا نشده |
| رویداد معتبر Lambda | 202 / stored=false | اجرا نشده |
| مختصات اشتباه | 422 | اجرا نشده |
| درخواست HTTP امضاشده | 202 | اجرا نشده |
| درخواست بدون امضا | 401/403 | اجرا نشده |
| مشاهده اجرای Lambda در CloudWatch | بله | اجرا نشده |
| حذف منابع و تأیید کنسول | بله | هنوز تأیید نشده |
