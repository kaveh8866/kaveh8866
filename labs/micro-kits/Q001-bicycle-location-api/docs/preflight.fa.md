# سؤال ۰۰۱ — پیش‌بررسی هزینه و مجوزها

[English](preflight.en.md)

**تا پاسخ به تمام موارد روشن نشده، هیچ منبعی ایجاد نکن.** API Gateway، Lambda و CloudWatch ممکن است به‌ترتیب برای درخواست، اجرای تابع و نگهداری لاگ هزینه داشته باشند. پلن رایگان یا اعتبار موجود تضمین رایگان‌بودن همه سرویس‌ها نیست؛ وضعیت حساب و صفحات رسمی [API Gateway](https://aws.amazon.com/api-gateway/pricing/)، [Lambda](https://aws.amazon.com/lambda/pricing/) و [CloudWatch](https://aws.amazon.com/cloudwatch/pricing/) را بررسی کن.

## چک‌لیست

- [ ] می‌دانم حسابم Free است یا Paid، چه مقدار اعتبار و تا چه تاریخی دارد.
- [ ] قیمت همان Region و امکان استفاده از HTTP API، Lambda، IAM و CloudWatch را بررسی کرده‌ام.
- [ ] با یک هویت **غیر Root** و MFA کار می‌کنم که مجوز ساخت **و حذف** منابع آزمایش را دارد.
- [ ] فقط یک Region انتخاب کرده‌ام و نام‌های احتمالی `aws-micro-q001-*` را با منابع موجود مقایسه کرده‌ام؛ منابع دیگران را تغییر نمی‌دهم.
- [ ] می‌دانم فراخواننده به `execute-api:Invoke` احتیاج دارد و درخواست با SigV4 امضا می‌شود؛ هیچ کلید دسترسی را در مخزن قرار نمی‌دهم.
- [ ] در این کیت **DynamoDB، Kinesis، Flink، Redshift، NAT Gateway، VPC Endpoint** یا سرویس اضافی پرهزینه ایجاد نمی‌کنم.
- [ ] زمان آزمایش (مثلاً ۲۰ دقیقه) و تعداد درخواست‌ها (مثلاً ۵ بار) را برای خودم محدود کرده‌ام؛ این‌ها **سقف فنی هزینه نیستند**.
- [ ] برنامه حذف و بررسی API/Stage، Lambda، نقش IAM و گروه لاگ CloudWatch را آماده دارم.
- [ ] اگر وضعیت مالی، مجوز یا پاک‌سازی نامشخص است، فقط کنسول را مشاهده می‌کنم و تست محلی اجرا می‌کنم.

**هزینه مورد انتظار:** برای چند درخواست بسیار کوچک و حساب واجد شرایط، معمولاً ناچیز؛ اما **صفر تضمین‌شده نیست**. بدون تأیید حساب عدد ثابت اعلام نکن. Endpoint غیرفعال از Endpointی که صرفاً Throttling دارد امن‌تر است. Terraform نگهداری لاگ را یک روز تنظیم می‌کند، ولی گروه لاگ همچنان باید پس از آزمایش حذف شود.

## مفهوم حداقل مجوز

- **نقش اجرایی Lambda:** اعتماد به `lambda.amazonaws.com` و فقط مجوز لازم برای لاگ خود تابع؛ نه دسترسی آزاد به داده‌ها.
- **هویت فراخواننده:** مجوز `execute-api:Invoke` محدود به ARN مشابه `arn:aws:execute-api:REGION:ACCOUNT_ID:API_ID/$default/POST/locations`؛ مقادیر واقعی را خصوصی نگه دار.
- **اجراکننده Terraform:** برای ایجاد و حذف API Gateway v2، Lambda، نقش و اتصال Policy و Log Group مجوز جداگانه نیاز دارد؛ این مجوز با فراخوانی API متفاوت است.

## شرایط توقف

هزینه غیرمنتظره، نبود مجوز، مسیر عمومی بدون IAM، منابع با مالکیت نامشخص، یا ناتوانی در حذف منابع: **اجرای آزمایش را متوقف کن و اول مسئله را حل کن.**
