### How I work

I prefer **small reproducible deployments**, clear APIs, automated checks, separated secrets, infrastructure-as-code where useful, and provider-neutral application packaging. My cloud projects aim to run in containers on Linux hosts; supported cloud providers are verified and documented individually.
